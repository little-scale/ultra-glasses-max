# Binary distribution gate

This document is a release-safety checklist, not legal advice.

The VITURE SDK is proprietary. Its current license permits SDK object code to
be distributed only as a component of a developed program and imposes further
conditions. Before publicly distributing the compiled Max package:

1. Read the current
   [VITURE SDK License Agreement](https://www.viture.com/viture-sdk-license-agreement).
2. Confirm that the package and its name satisfy the current agreement.
3. Supply an end-user agreement that includes every condition VITURE requires,
   including the restrictions and indemnity language described by the SDK
   agreement.
4. Retain all applicable VITURE copyright and trademark notices.
5. Include `THIRD_PARTY_NOTICES.md` in the package.
6. Obtain written permission from VITURE before using its trademarks in
   marketing or implying endorsement or certification.
7. Contact `bd@viture.com` if the SDK will be used for a business purpose or if
   any distribution term is unclear.

The repository name and package identity are `ultra-glasses-max` and
`UltraGlassesMax`. Existing external object names are retained for Max patch
compatibility; confirm that this API naming is acceptable before public binary
distribution.

The source repository does not distribute the SDK and may be published
separately from compiled binaries.
